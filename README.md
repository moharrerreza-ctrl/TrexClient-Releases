# TrexClient

Official downloads for **TrexClient** — a Minecraft launcher and client made for the TrexMine server.

## Download

Get the latest installer from the [Releases page](../../releases/latest):
`TrexClient-Setup-<version>.exe`

## Install

1. Run `TrexClient-Setup-<version>.exe`.
2. Windows may show a blue "Windows protected your PC" screen because the app is not code-signed yet.
   Click **More info → Run anyway**.
3. Choose an install folder and finish the setup.

TrexClient updates itself automatically after it is installed.

## Requirements

- Windows 10 or 11 (64-bit)
